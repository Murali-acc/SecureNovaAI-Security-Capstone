# SecureNova AI – Security Capstone Portfolio

## Overview
This portfolio documents the design, implementation, testing,
and governance of security controls for a simulated AI application.

## Projects

1. Threat Modeling
2. Identity and Access Management
3. Red Team – AI Identity Attacks
4. Blue Team – AI Security Defenses
5. Policy, Compliance and Summary

## Security Objectives
- Secure AI agent identities
- Protect API credentials and tokens
- Identify and simulate AI-specific attacks
- Implement defensive security controls
- Evaluate compliance and residual risks

## Technology Stack
- Python
- Flask
- Auth0
- OAuth 2.0 / OpenID Connect
- JWT
- TensorFlow / supporting security libraries where applicable
- NeMo Guardrails
- Git and GitHub

## Disclaimer
This is a simulated educational security project.
All attack credentials and test identities are fictional.
