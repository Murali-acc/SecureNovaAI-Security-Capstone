# Project 1 – Threat Modeling

## Objective
Identify security threats across the SecureNova AI architecture.

## Methodology
- Identity inventory
- Data Flow Diagram (DFD)
- Trust boundary identification
- STRIDE threat analysis
- Risk assessment and prioritization

## Deliverables
- Data Flow Diagram
- Identity Inventory
- STRIDE Threat Matrix
- Risk Register

## Security Focus
Authentication, authorization, identity spoofing, tampering,
information disclosure, and privilege escalation.
