# Project 3 – Red Team: AI Identity Attacks

## Objective
Simulate attacks against the SecureNova AI agent.

## Attack Scenarios
- Indirect prompt injection
- Agent identity spoofing
- System prompt extraction
- Prompt-based privilege escalation
- RAG poisoning and MCP abuse

## Deliverables
- Attack payloads
- Attack execution logs
- CVSS findings
- MITRE ATLAS mapping
- Attack success matrix

## Note
All credentials and tokens used in attack simulations are fake.
