# Project 4 – Blue Team: AI Security Defenses

## Objective
Implement and test defensive controls against the Project 3 attacks.

## Security Controls
- NeMo Guardrails
- JWT credential redaction
- Ed25519 message signing
- Short-lived access tokens
- Refresh-token rotation
- Risk-based authentication
- Anomaly detection and alerts

## Evaluation
Replay the five simulated attack scenarios and compare
before-and-after security results.

## Deliverables
- Defensive implementation
- Attack replay results
- Security alerts
- Before-and-after comparison
- Final results report
